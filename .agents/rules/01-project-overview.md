# 项目概述 

**GeoInsight BI** 是一个现代化的地理信息商业智能平台。它采用“微内核+插件”的设计理念，结合**前后端分离**的架构，允许用户在动态交互的地图底图上，根据需求自由挂载、排列和组合各种分析组件（如统计图表、AI 聊天助手、图层管理器等）。

## 架构理念
项目采用典型的前后端分离架构，通过 RESTful API 进行交互：
- **Frontend (frontend/)**: 基于 React 和 OpenLayers 的交互式地图前端，负责空间数据展示与交互。
- **Backend (backend/)**: 基于 Spring Boot 的业务逻辑后端，负责空间数据存储、业务处理及 AI 集成。

## 设计目标
1. **高度模块化**：功能通过插件实现，核心框架与业务逻辑解耦。
2. **分离架构**：前后端工程解耦，独立部署与开发。
3. **动态交互**：支持插件窗口的自由拖拽、缩放和布局管理。
5. **高性能地图**：基于 OpenLayers 构建稳定、流畅的地图底座。
